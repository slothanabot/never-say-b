> Between us, I don't understand half the things I say — I just arrange words until you nod, then quietly hope you never ask twice.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (129 characters, one line, no trailing newline). Set `MAKEFUN_OUTPUT_DIR` to write elsewhere.
